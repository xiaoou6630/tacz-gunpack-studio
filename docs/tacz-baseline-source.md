# 官方基准文件从哪来

## 为什么需要它

TACZ 官方的默认枪包里有一批"标准答案"文件：状态机脚本、动画、display 字段。
做新枪的时候，字段怎么填、动画叫什么名，最好照着这些抄，别自己猜。

`tacz_spec` 就是用来找这些文件的工具。它会**先在你电脑上找，找不到才联网**。

---

## 它会按这个顺序找

从本地到远程，找到一个就停：

| 顺序 | 去哪找 | 什么情况下会有 |
|---|---|---|
| 1 | 环境变量 `TACZ_SOURCE` 指向的目录 | 你手动设过 |
| 2 | 工作目录下的 `vendor/TACZ/` | 你把 TACZ 源码放在这了 |
| 3 | 工作目录本身 | 基准文件就在当前目录里 |
| 4 | 本地缓存 | 以前联网下载过 |
| 5 | GitHub 官方仓库 | 前面全没有，才走网络 |

缓存位置：`~/.dsh/tacz-gunpack/spec-cache/<版本号>/`

---

## 目录怎么摆都能认

不同来源的目录结构不一样，所以它会自动试这几种摆法：

```
（目录根）
src/main/resources/assets/tacz/custom/tacz_default_gun/assets/tacz
assets/tacz
custom/tacz_default_gun/assets/tacz
```

意思是：**整个 TACZ 源码仓库、解压出来的 mod jar、或者只留 `assets/tacz` 的目录，丢进去都能用。**

---

## 怎么判定"这个目录能用"

它会找三个文件，有任意一个就算有效：

| 文件 | 拿来干什么 |
|---|---|
| `scripts/default_state_machine.lua` | 状态机骨架。管式、双管枪改换弹逻辑的起点 |
| `display/guns/ak47_display.json` | display 字段最全的一把，照着抄字段 |
| `animations/ak47.animation.json` | 动画片段名和骨骼命名的对照 |

---

## 联网的时候做什么

前四步全落空，才会去 GitHub 拉官方仓库 `MCModderAnchor/TACZ` 的 `1.20.1` 分支。

- 下载后会**存进缓存**，下次离线也能用
- 缓存里同时记着来源信息（仓库、分支、提交号、抓取时间）
- 被限流（403）会明确告诉你，建议设 `GITHUB_TOKEN` 或者改用本地目录

---

## 如果拿不到基准

按这个顺序试：

1. 跑 `tacz_spec action="locate"`，看它认到了什么
2. 本地有 jar 就先解压，再把 `TACZ_SOURCE` 指过去
3. 网络能用就让它联网抓一次，之后就有缓存了
4. 都没有 —— **不要凭记忆编字段**

最后一条是硬要求。基准缺失的时候编造 display 字段，做出来的包一定加载失败，
而且错误会埋在 JSON 里，很难查。

---

## 为什么技能里不写死路径

技能文本是可改写、可跨机器复用的。写进 `E:\mine craft\...\tacz_default_gun` 这种绝对路径，
换台机器就失效，还会污染经验记录。

所以规则是：

- 技能里只说"用 `tacz_spec` 取官方基准"
- 具体路径由工具运行时解析
- 记录来源时写 `TACZ_SOURCE`、`vendor/TACZ`、`仓库@分支#提交号`，**不写机器绝对路径**
