# 官方美术标准，和 KSG 差了多少

拿一把真做过的枪（KSG）对着官方标准量了一遍，看看差在哪。
这份既是标准清单，也是一份"体检报告"。

依据官方 Wiki：模型建造指南（[设置](https://tacwiki.mcma.club/zh/model_guide/setting.html)、[建模](https://tacwiki.mcma.club/zh/model_guide/model.html)、[贴图](https://tacwiki.mcma.club/zh/model_guide/texture.html)）、[特殊组名](https://tacwiki.mcma.club/zh/gunpack/gun/03_sp_group_name.html)、[手臂定位](https://tacwiki.mcma.club/zh/gunpack/gun/04_hand_pos.html)、[视觉定位](https://tacwiki.mcma.club/zh/gunpack/gun/05_gun_position.html)、[HUD](https://tacwiki.mcma.club/zh/gunpack/gun/display/03_hud.html)、[LOD](https://tacwiki.mcma.club/zh/gunpack/gun/06_lod.html)。

---

## 一、官方标准是什么

### 尺寸和比例

**核心换算：1000 毫米 = 48 格。**

所以一把真枪长度是 L 毫米，模型长度就是 `48 × L / 1000` 格。

一把 26 英寸（662.9 毫米）的枪，模型应该 31.8 格长。

### 形状

- 模型关于 Z-Y 平面对称，枪管朝 -Z（北）
- 尺寸最好取 0.125 的倍数，方便 UV 对齐

### 导轨（很关键）

- 底部宽 **0.75 格**
- 常用齿型：1-3-1 或 1-5-1
- 一个导轨单位是 0.25 格

### 圆形的做法

| 半径 | 怎么做 |
|---|---|
| 大于 1 | 用八边形 |
| 小于 0.75 | 可以用单方块 |
| 小于 0.5 | 可以用单方块 |
| 很大 | 可以上十六边形 |

尽量做实心，别留空腔。

### 避免面闪烁（Z-fighting）

交叉的面用 `inflate ±0.001–0.005` 错开。垂直交叉尽量避免。

### 面数参考

| 类型 | 官方参考 |
|---|---|
| 高模 ak47 | 761 个方块 |
| 高模 m870 | 273 个方块 |
| LOD 低模 | 25–50 个方块 |

### 贴图

- **逐面 UV**，面矩形应该唯一，不要重叠
- 贴图只画实际用到的区域
- **枪铁是低饱和的**：饱和度 ≤20，5–10 最合适；色相偏蓝-青
- 亮面低饱和，暗面可以高纯度
- 避免纯黑和纯白
- 要有明暗交界、AO（环境光遮蔽）、抖动（dither）

### 图标

| | 要求 |
|---|---|
| 槽位图 | 64×64；等轴朝右（2:1）；关阴影；裁掉透明边。官方 m870 是 438 色 |
| HUD | 3:1（180×60 / 192×64 / 384×128）；侧视、枪口朝左。官方 m870 是 384×128、80 色 |

### 分组

- 手：`lefthand_pos` / `righthand_pos`。官方父组是 `bullet_and_lefthand`、`gun_and_righthand`
- 视角：`views/idle_view/iron_view/ground/thirdperson_hand/fixed` 必须存在且非零
- LOD：独立的 `lod` 组，25–50 个方块，display 里写 `lod.model` 和 `lod.texture`

## 二、KSG 实测差多少

| 项 | 官方要求 | KSG 实际 | 差多少 |
|---|---|---|---|
| 总长 | 26.1 英寸 → **31.8 格** | **37.5 格** | **超了 17.8%** |
| 宽 | 3 英寸 → **3.66 格** | **4.84 格** | **超了 32%** |
| 高 | 7 英寸 → **8.53 格** | **10.0 格** | **超了 17%** |
| 导轨 | 底宽 0.75，1-5-1 齿型 | 3.4 宽的整条板，7 个方块 | 太宽，没有齿型 |
| 枪管 | 八边形或多片 | 1 个 1.3×1.3 的实心方块 | 方块感很重 |
| 面数 | 273–761 个 | **69 个** | 只有 LOD 级别 |
| UV | 逐面唯一 | **6361 对面重叠**，大量面共用同一块 | 严重重叠 |
| UV 覆盖 | 按面唯一铺开 | 15%，而且是重复的 | 覆盖无效 |
| 贴图 | 官方 m870 是 256×256、424 色 | 128×128、**36 色**、整张不透明 | 颜色和细节严重不足 |
| 槽位图 | 官方 438 色 | 36 色 | 图标平、暗 |
| HUD | 384×128、80 色 | 192×64、36 色 | 尺寸和细节都不够 |
| LOD | 必须有 | 没有 | 缺 |
| 声音/枪口火焰/副手/快捷栏 | display 可选，但官方默认包都有 | 没有 | 缺 |

## 三、结论

**KSG 的问题不是"美术不够好"，是"没按官方建模规范做"。**

具体五条：

1. **整体偏大 18–32%**，所以第一人称里显得巨大，手位很难对
2. **导轨和枪管是"一个大方块"**，不是官方的 0.75 导轨 + 八边形枪管
3. **69 个方块是 LOD 级别**，不是高模。细节不足，导致图标和轮廓都不像官方
4. **UV 大面积重叠**（6361 对面），贴图只有 36 色且整张不透明，所以槽位图和 HUD 又平又暗
5. **缺 LOD、枪口火焰、声音、副手/快捷栏**

---

## 四、怎么修

按这个顺序来：

1. **重做几何**：总长收到 31.8 格；宽收到 3.66；高收到 8.53
2. **导轨**：底宽 0.75，1-5-1 齿型，0.25 一格；别再整条板
3. **枪管和弹仓**：八边形截面，至少 8 片；弹仓管也一样
4. **面数**：高模提到 200 个方块以上；LOD 单独做 25–50 个
5. **UV 重排**：逐面唯一矩形，消掉 6361 个重叠；按实际面尺寸分配
6. **贴图**：128 或 256；低饱和蓝灰；做出亮面和暗面的层次；加 AO 和抖动；不要整张黑底
7. **重出图标**：槽位图用等轴 64、关阴影、裁透明边；HUD 用 384×128、3:1、侧视、枪口朝左
8. **补齐 display**：lod、muzzle_flash、sounds（可以复用官方的）、offhand/hotbar
9. 重新审核、重新打包。旧的审核（绑定的是老指纹）自动失效

**这不是十分钟能补完的，是几何和数据两阶段的美术重做。**
